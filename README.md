# 智能任务管理系统

基于 Node.js + React + Supabase 的全栈任务管理应用。

## 功能

- 输入任务标题并选择优先级（高/中/低）添加任务
- 任务列表按创建时间倒序显示
- 支持切换完成状态、删除任务
- 按优先级筛选（全部/高/中/低）
- 已完成任务自动加删除线并变淡
- 数据持久化存储在 Supabase 云端数据库

## 技术栈

- 后端：Node.js + Express
- 前端：React + Vite
- 数据库：Supabase (PostgreSQL)
- 部署：Vercel

## 本地开发

### 1. 安装依赖

```bash
npm install
cd client && npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的 Supabase 凭据：

```env
SUPABASE_URL=https://你的项目ID.supabase.co
SUPABASE_ANON_KEY=sb_publishable_你的key
```

### 3. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173

## Supabase 建表 SQL

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table tasks enable row level security;

create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

## 部署到 Vercel

1. 将代码推送到 GitHub 仓库
2. 在 Vercel 导入该仓库
3. 配置环境变量 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`
4. 点击 Deploy

> 注意：`.env` 文件已加入 `.gitignore`，请勿将密钥提交到 GitHub。
